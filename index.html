Projets & Réalisations

LOGICIEL DE GESTION DÉMO SUR DEMANDE ↗

Comptoir — devis, factures et relances

Logiciel de gestion que j'ai conçu de A à Z pour les indépendants et les petites entreprises. Les devis s'acceptent en ligne en un clic, les factures sont conformes à la loi française et déjà au format électronique Factur-X (validé avec veraPDF et les validateurs officiels), les impayés sont relancés automatiquement par email.

On y suit aussi ses prospects, ses projets et son temps passé, avec le livre des recettes et les exports pour le comptable. Il s'installe sur n'importe quel hébergement, sans abonnement, et les données restent chez le client.

PHP 8 MySQL / MariaDB JavaScript Factur-X / EN 16931 PDF/A-3 SMTP
BOUTIQUE E-COMMERCE CODE ↗

Brûlerie du Phare — boutique en ligne

Boutique e-commerce complète pour une brûlerie de café : catalogue filtrable, fiches produits, panier avec quantités, frais de port et seuil de livraison offerte, puis tunnel de commande et paiement. Thème clair/sombre, pensée pour le mobile, panier conservé d'une visite à l'autre.

Réalisée en JavaScript natif, sans aucune dépendance : elle se publie telle quelle. Pour la partie paiement sécurisée côté serveur, voir le projet Guichet.

JavaScript HTML / CSS Panier & commande Responsive localStorage
IDENTITÉ VISUELLE VOIR LE SITE ↗

Maison Écume — cahier de marque

Identité complète pour une marque fictive de fleur de sel de la Côte d'Opale : logo et sa construction, palette avec codes HEX, RVB et CMJN, typographies, règles d'usage et mises en situation (carte de visite, étiquette, icône d'appli).

L'emblème de couverture est dessiné en direct : ses lignes de houle bougent au passage de la souris et suivent un curseur gradué sur l'échelle de Beaufort.

Logo SVG Charte graphique Canvas HTML / CSS
APPLICATION WEB CODE ↗

DevShelf

Application pour centraliser et retrouver des ressources techniques. Moteur de recherche et d'analyse de texte écrit en Rust, appelé depuis une API Python (FastAPI), base SQLite et interface React.

Rust Python / FastAPI React SQLite
ANALYSE DE DONNÉES CODE ↗

Analyse des données ouvertes du CERN

Traitement de 100 000 collisions réelles enregistrées par le détecteur CMS du LHC. Le script retrouve les mêmes particules que les publications officielles (J/ψ, Upsilon, boson Z), avec tests automatisés.

Python Données Tests
